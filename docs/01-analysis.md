# 1. Анализ предметной области

## 1.1. Как работает мастерская по ремонту техники

Сервисный центр принимает от клиентов неисправные устройства (смартфоны, ноутбуки, планшеты, игровые
консоли), проводит диагностику, согласует стоимость, ремонтирует и выдаёт устройство обратно.

Типовой жизненный цикл заявки:

```
Приём → Диагностика → Ремонт → Готово к выдаче → Выдано
```

Участники процесса:

| Роль | Что делает |
|---|---|
| Клиент | Сдаёт устройство, описывает неисправность, узнаёт статус, забирает и оплачивает |
| Мастер | Диагностирует, ремонтирует, списывает запчасти, пишет комментарии |
| Администратор (приёмщик/руководитель) | Распределяет заявки между мастерами, ведёт прайс и склад, смотрит показатели |

Проблемы, которые чаще всего возникают без информационной системы:

- клиент звонит, чтобы узнать статус, и отвлекает мастеров;
- заявки записаны в тетради или таблице, история ремонта устройства теряется;
- непонятно, какие запчасти ушли в какой ремонт и почему на складе расхождение;
- нет данных для решений: какие поломки самые частые, кто из мастеров перегружен, сколько заработано за месяц.

## 1.2. Обзор аналогов

| Решение | Тип | Сильные стороны | Ограничения для небольшой мастерской |
|---|---|---|---|
| RemOnline | облачная CRM для сервисных центров | заказы, склад, касса, уведомления | платная подписка, избыточна для 2–3 мастеров |
| LiveSklad | облачная CRM для сервисов | заказы, склад, статусы для клиента | платная, интерфейс рассчитан на сотрудников, а не клиентов |
| Конфигурации 1С для сервисных центров | настольное ПО | интеграция с бухгалтерией | дорогое внедрение, нет личного кабинета клиента «из коробки» |
| Таблицы (Excel, Google Sheets) | универсальный инструмент | бесплатно, просто | нет ролей и прав, нет истории, клиент не видит статус |

Вывод: для небольшой мастерской нужно лёгкое веб-приложение, где клиент сам оформляет заявку и следит за
статусом, а сотрудники ведут ремонт и склад в одной системе. Такую систему и разрабатываем.

## 1.3. Границы проекта

Входит: каталог услуг, онлайн-заявка с фото, личные кабинеты трёх ролей, история статусов, комментарии,
склад запчастей с журналом движений, расчёт стоимости, статистика с графиками, публичная проверка статуса
по коду.

Не входит (возможное развитие): онлайн-оплата, касса и фискальные чеки, SMS-уведомления, интеграция с
поставщиками запчастей.
